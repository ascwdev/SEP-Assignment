# SEP Assignment

Code critique assignment with command pattern implementation for SWE module.

## Introduction

This project is part of an assignment in which I was to write a critique on a program I was provided. Within this assignment, I had to highlight issues with the code and offer solutions, as well as implement them, and document evidence of this.

I performed static analysis testing using various methods, as well as unit testing using JUnit. I also implemented a command pattern design to replace the poor if/else chain handling of commands.

Evidence of my findings can be found in `critique.docx` or `critique.pdf`. `/src` contains the program following my implementation, and `/original-src` contains the original program for comparison.
